# Weekly Task Files

This directory contains detailed task breakdowns for each week of the project.

## Structure

Each week has its own markdown file with:
- Detailed checklist of tasks
- Time estimates for each section
- Agents to use for that week
- Expected deliverables
- Common pitfalls and solutions
- Definition of "done" for the week

## How to Use

1. **Load only the current week** - Saves tokens vs loading the full PROJECT_PLAN.md
2. **Reference PROJECT_SUMMARY.md** for high-level overview
3. **Come back here** when you finish a week and need the next one

## Creating New Week Files

When creating a new week file, include:
- Week number and title
- Goal statement
- Detailed checklist with sub-tasks
- Agents to use (from AGENT_WORKFLOW.md)
- Expected outputs/deliverables
- Tips & common issues
- Definition of done

## Token Savings

- **Old approach:** Load PROJECT_PLAN.md (~2000 lines) every time
- **New approach:** Load PROJECT_SUMMARY.md (~200 lines) + current week (~300 lines)
- **Savings:** ~75% fewer tokens per session!
